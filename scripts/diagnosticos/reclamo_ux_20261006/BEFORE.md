# Estado visual anterior

La página presenta los trece paneles en una sola columna continua. El botón de publicación está junto a “Actualizar” y “Recalcular reclamo”; el historial de alertas se titula como pendiente aunque incluye eventos de ejecuciones anteriores. Los formularios de edición e inserción de datos base se muestran completos al mismo tiempo.

Capturas desktop: `before/reclamo_1366x768.png` y `before/reclamo_1920x1080.png`. Son capturas de un preview local del layout del checkout. Las consultas DEV en ese preview devolvieron mensajes de conexión por restricciones TLS del proceso local; las capturas sirven para comparar estructura, jerarquía y responsividad, no cifras operacionales.
